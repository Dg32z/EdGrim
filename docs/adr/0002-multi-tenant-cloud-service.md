# 云端采用多租户共享实例

一个共享实例服务多个服主，样本汇总训练单一全局模型，而不是每个服务器各自部署一个实例。

选它是因为跨服样本池是云端推理相对本地推理唯一的实质增益：单服样本量不足以支撑一个比 28 个 Aim* 检查更强的模型，汇总之后才可能。代价是写插件的人变成托管他人服务器数据的**数据处理者**，需要租户隔离、配额、滥用防护，以及删除权机制；同时单个租户的异常数据会进入共享模型，影响其他租户的判定。

## Considered Options

- **一服一实例自建**：隐私最干净、运维最轻，数据不出服主自己的机器；但样本池等于单服，模型增益有限，且与「云端」的定位相矛盾。
- **一服一实例 + 可选贡献样本到公共池**：折中方案，默认自建、愿意的服主上报样本；但需要维护两套部署形态，且贡献者的样本仍进入公共模型，隔离性与自建版不一致。

## Consequences

需要租户级 salt（而非 per-server salt，否则同一服主的多服之间也无法关联）、租户级样本权重（防止样本量大的租户主导模型）、以及按玩家哈希的删除权实现。
